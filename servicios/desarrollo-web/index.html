Preguntas frecuentes

Dudas habituales sobre desarrollo web

¿Cuánto cuesta una página web profesional?

Una web corporativa parte de 500 € + IVA, pago único. Una web más amplia con blog, desde 900 € + IVA, y una tienda online, desde 1.500 € + IVA. El mantenimiento, con dominio, alojamiento, correo, copias de seguridad y soporte, desde 250 € + IVA al año. Si además necesitas una app de gestión interna para tu equipo, el pack Web + App parte de 4.500 € + IVA. Siempre recibes un presupuesto cerrado antes de empezar.

¿Cuánto se tarda en tener la web lista?

Una web corporativa suele estar publicada en dos o tres semanas desde que tenemos los contenidos y accesos (la Web Esencial). Una web más amplia o una tienda, en tres o cuatro semanas.

¿Por qué no usáis WordPress?

Porque para la mayoría de negocios es más lento, más inseguro y más caro de mantener. Construimos webs ligeras que cargan al instante, algo que Google premia en el posicionamiento. Si necesitas un gestor de contenidos, lo incluimos.

¿Incluye posicionamiento SEO?

Sí. Toda web sale con SEO técnico y on-page trabajado: estructura, títulos, descripciones, datos estructurados, velocidad, sitemap y SEO local. Si quieres crecer más, ofrecemos un plan mensual de contenidos y blog.

¿Puedo modificar la web yo mismo?

Sí. Te dejamos la web preparada para que actualices lo habitual sin depender de nadie, y te formamos para hacerlo.
